# 画面の試作について

ここにある `*.dc.html` は、claude.ai のデザインキャンバスで作った画面の試作です。見た目の参考資料で、**そのまま使うコードではありません**。

- `{{accent}}` などの二重波かっこ、`<sc-for>` `<sc-if>` `<x-dc>` は試作用の独自の書き方です。実装では普通の HTML と JavaScript に置き換えてください。
- 配色、余白、角丸、文字の大きさ、レイアウトは、インラインの `style` に書かれた値を正としてください。
- 表示されている数値(30.42、68.0kg など)はすべてサンプルです。

| ファイル | 画面 | 段階 |
| --- | --- | --- |
| Main.dc.html | ホーム(目標の常時表示、体重、ルーティン、下部ナビ) | 1 |
| Workout.dc.html | トレーニング記録中(タイマー、重さの内訳、セット、感触、片側の方式、加重懸垂の実負荷、プライオの高さ) | 1 |
| Picker.dc.html | 種目を選ぶ(部位タブ、器具の絞り込み、片側可の印) | 1 |
| Metrics.dc.html | 指標と目標(目標、推移を重ねるグラフ、立ち幅跳び・垂直跳びの試技) | 目標と試技は1、グラフは2 |
| TimeEntry.dc.html | プールのタイム入力 | 2 |

履歴と設定の画面は試作がないので、他の画面の見た目に合わせて作ってください。
